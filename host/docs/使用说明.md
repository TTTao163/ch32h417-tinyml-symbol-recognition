# MNIST 模型训练与嵌入式部署指南

## 训练结果

✅ **模型训练成功完成！**

- **测试准确率**: 99.69%
- **模型大小**: 113,104 bytes (约 110 KB)
- **量化类型**: INT8 全整型量化
- **输入尺寸**: 28x28x1 (灰度图像)
- **输出类别**: 10 类 (+, -, 0, 2, 4, 6, 8, divide, multiply, percent)

## 生成的文件

1. **mnist_model_quant.tflite** - TensorFlow Lite 量化模型文件
2. **mnist_model_data.h** - C语言头文件（用于嵌入式部署）

## 模型优化特性

### 1. 轻量级架构
- 使用深度可分离卷积 (SeparableConv2D) 减少参数量
- 精简的全连接层设计
- 总参数: 102,050 (约 398 KB)

### 2. 训练优化
- 数据增强（旋转、平移、缩放）
- 验证集分割 (20%)
- 早停机制 (EarlyStopping)
- 学习率自适应调整 (ReduceLROnPlateau)

### 3. 量化优化
- INT8 全整型量化
- 自动降级到 Float16（如果 INT8 失败）
- 代表性数据集校准

## 在 RT-Thread 中使用

### 步骤 1: 复制头文件
将 `mnist_model_data.h` 复制到你的 RT-Thread 项目中

### 步骤 2: 包含头文件
```c
#include "mnist_model_data.h"
```

### 步骤 3: 使用模型数据
```c
// 模型数据数组
const unsigned char* model_data = g_mnist_model_data;
unsigned int model_size = g_mnist_model_data_len;

// 模型参数
unsigned int classes = num_classes;        // 10
unsigned int input_w = input_width;        // 28
unsigned int input_h = input_height;       // 28
unsigned int input_c = input_channels;     // 1
```

### 步骤 4: 类别映射
```c
// 输出索引对应的类别:
// [0] = +
// [1] = -
// [2] = 0
// [3] = 2
// [4] = 4
// [5] = 6
// [6] = 8
// [7] = divide
// [8] = multiply
// [9] = percent
```

## 重新训练模型

如果需要重新训练或调整参数：

```bash
cd mnist
python train_to_tflm_DEPTHWISE_CONV_2D.py
```

### 可调整的参数

在脚本中可以修改：
- `BATCH_SIZE`: 批次大小（默认 64）
- `epochs`: 训练轮数（默认 20，带早停）
- 数据增强参数（rotation_range, zoom_range 等）
- 模型架构（卷积层数、滤波器数量等）

## 注意事项

1. **内存对齐**: 模型数据使用 `__attribute__((aligned(16)))` 确保 16 字节对齐
2. **输入格式**: 输入图像需要是 28x28 灰度图，像素值归一化到 [0, 1] 或转换为 INT8
3. **量化感知**: 模型已经过 INT8 量化，推理时使用整数运算
4. **TensorFlow Lite Micro**: 需要在嵌入式项目中集成 TFLM 库
